# Anni

Anni downloads videos, music, images and files from more than 1,000 sites, including YouTube, Instagram, X, Facebook, Reddit, SoundCloud and Vimeo. It also downloads torrents and converts any video, audio or image file to the format you need. It runs on Windows and Mac.

**Download:** [ravulacharan.com/anni](https://ravulacharan.com/anni/) · [Latest release](https://github.com/ravulacharan-rc/anni/releases/latest)

## What's here

This repository holds Anni's **releases**. Each release has:

| File | For |
| --- | --- |
| `Anni-Setup-X.Y.Z.exe` | Windows 10 and 11 (64-bit) |
| `Anni-X.Y.Z-mac-arm64.dmg` | Macs with Apple silicon (M1 and later) |
| `Anni-X.Y.Z-mac-x86_64.dmg` | Macs with an Intel processor |

Anni checks here for new versions by itself. When one is out, it offers it in **Settings › Updates**, downloads it, checks its SHA-256 and installs it.
